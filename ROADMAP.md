# Roadmap

This roadmap is intentionally concise. It describes direction without acting as a private task queue.

## Initialization

- Establish the repository structure and open project documents.
- Define core terms for local workspaces, encrypted records, agent actions, plugins, sync, and SDK surfaces.
- Draft architecture notes for capability scopes, audit events, and encrypted data flow.

## Foundation

- Build a minimal local workspace model with encrypted storage.
- Define agent action records that are easy to review and audit.
- Prototype plugin registration with least-privilege capabilities.
- Sketch SDK interfaces for workspace access, agent actions, and sync events.

## Product Shape

- Add encrypted multi-device sync with clear conflict handling.
- Provide developer tools for plugin testing and audit inspection.
- Expand SDK coverage for common automation workflows.
- Harden key handling, recovery flows, and local backup paths.

## Maturity

- Document stable extension points.
- Add compatibility tests for plugins and SDK clients.
- Improve observability for agent and sync behavior.
- Prepare release notes and migration guidance as interfaces stabilize.
